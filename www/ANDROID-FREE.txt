PULSE Insight — free HTML / PWA build
=====================================

Play on phone (same Wi‑Fi as PC):
  http://192.168.1.230:8765/pulse-preview/index.html?v=3

Install free on Android (no Play Store / no Cursor Pro):
  1) Open that link in Chrome
  2) Menu (⋮) → Add to Home screen / Install app
  3) Opens full-screen like an app; works offline after first load

Later paid steps (optional):
  - Google Play $25 one-time to publish
  - Cursor Pro $20/mo only if you want Flutter Cloud Agents
